## Lisp Image
- [What is a Lisp image? - StackOverflow](https://stackoverflow.com/questions/480083/what-is-a-lisp-image)
- The image is usually a file, a dump of the memory of a Lisp system, contains all functions, variable values, symbols, etc of the Lisp system.
- [SBCL - Saving a Core Image](https://www.sbcl.org/manual/index.html#Saving-a-Core-Image)
- [Base Lisp Image](https://github.com/40ants/base-lisp-image): Base image for Common Lisp projects with SBCL or CCL and latest ASDF, Qlot and Roswell
