# ClojureScript
* https://clojurescript.org/
* https://github.com/clojure/clojurescript

> ClojureScript is a compiler for Clojure that targets JavaScript. It emits JavaScript code which is compatible with the advanced compilation mode of the Google Closure optimizing compiler.

# Tools

Testing: ClojureScript now ships with a port of `clojure.test` in the form of `cljs.test`. It attempts to preserve most of the functionality provided by `clojure.test` along with enhancements for asynchronous testing in a single threaded environment.
