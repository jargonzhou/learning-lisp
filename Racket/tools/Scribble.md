# Scribble: The Racket Documentation Tool
* https://docs.racket-lang.org/scribble/index.html

> Scribble is a collection of tools for creating prose documents—papers, books, library documentation, etc.—in HTML or PDF (via Latex) form. 
> More generally, Scribble helps you write programs that are rich in textual content, whether the content is prose to be typeset or any other form of text to be generated programmatically.
